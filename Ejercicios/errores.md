# Codigos de salida comun en bash

## #!/bin/bash

0 Éxito. Indica que el script o comando terminó sin errores.
1 Error genérico o fallo en el comando.
2 Uso incorrecto de un comando o sintaxis incorrecta.
126 Permiso denegado (el archivo no tiene permisos de
ejecución).
127 Comando no encontrado.
128 Error de argumento inválido para el comando exit.
130 Script terminado con la señal SIGINT (interrupción,
como presionar Ctrl+C).
137 Terminado con la señal SIGKILL.
255 Código de salida fuera del rango permitido (mayor).
